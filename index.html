HR System & Payroll

An employee management and payroll web application built with PHP and Supabase — manage employees, positions, departments, and records in one place.

Log In Back to My Portfolio

What it does

Features

Employee Records

Personal information, photos, emergency contacts, dependents, education, character references, and position history.

Departments

Browse employees by department, filter, and search the whole workforce quickly.

Admin Dashboard

Add, edit, delete, and print employee records with a logged audit trail of every action.

Built with

Tech Stack

PHP (XAMPP)

Server-rendered pages with session-based admin authentication.

Supabase

Postgres database accessed over the PostgREST HTTPS API.

HTML & CSS

Custom-styled UI using the same palette as my portfolio.
