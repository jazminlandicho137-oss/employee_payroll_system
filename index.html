HR System & Payroll

An HR & payroll web application built with PHP and Supabase.

About

This project is an employee information and payroll-management system. Admins can manage employees, their personal information, emergency contacts, dependents, educational background, character references, and job positions, with an audit log of every action.

Tech Stack

  • PHP (XAMPP)
  • Supabase (PostgREST REST API)
  • HTML, CSS, JavaScript

Setup

  1. Place the project inside C:\xampp\htdocs.
  2. Start Apache from the XAMPP control panel.
  3. Open pages/login.php in your browser.

Color Palette
